### Help / Discoverability
Clawbox — containerized AI coding agent

Usage: clawbox <command> [args]

Commands:
  start              Start the container
  stop               Stop the container
  restart            Stop then start
  status             Show container + gateway status
  logs               Tail container logs
  chat               Open interactive TUI chat session
  run "message"      Send a one-shot message to the agent
  ask "question"     Alias for run — send a question to the agent
  task "description" Run a task in the background
  task-status        Check background task progress
  cp <src> <dest>    Copy file into container (fixes ownership)
  shell              Open a shell inside the container
  logs-tail          Show last 50 lines of today's gateway log
  backup             Backup agent state to tar.gz
  restore <file>     Restore agent state from tar.gz
  upgrade            Rebuild image with latest OpenClaw
  clean              Stop container and delete all data
  install            Install clawbox CLI to /usr/local/bin
  help               Show this help

Environment:
  CLAWBOX_DIR        Path to clawbox project (default: script directory)
