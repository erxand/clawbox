### Help / Discoverability
Clawbox — containerized AI coding agent

Usage: clawbox <command> [args]

Commands:
  start              Start the container
  stop               Stop the container
  restart            Stop then start
  status             Show container + gateway status
  logs               Tail container logs
  chat               Open interactive TUI chat session
  chat --session <name>  Open TUI with a named session (persistent per-project threads)
  run "message"      Send a one-shot message to the agent
  run --context <path> "msg"  Inject file/dir as context before the message
  run --thinking <level> "msg"  Set thinking level (off|minimal|low|medium|high|xhigh)
  run --session <name> "msg"  Use a named session (persistent conversation thread)
  run --quiet "msg"  Suppress status banners; print only the agent's response
  run --json "msg"   Output result as JSON {response, elapsed_ms, timestamp, context_files, session}
  run --retry <n> "msg"  Retry up to N times (60s delay) if API rate-limited (exit 2 on limit)
  ask "question"     Alias for run — supports the same flags
  task "description" Run a task in the background (output saved to ~/.clawbox-task.log)
  task --context <path> "desc"  Background task with file/dir context
  task --thinking <level> "desc"  Background task with thinking level
  task --session <name> "desc"  Background task in a named session
  task --timeout <min> "desc"  Kill agent after N minutes; send handoff prompt to update TASK.md
  task-status        Check background task progress + last task output
  task-logs          Live tail of background task output (tail -f ~/.clawbox-task.log)
  cancel             Cancel the currently running background task
  cp <src> <dest>    Copy file into container (fixes ownership)
  shell              Open a shell inside the container
